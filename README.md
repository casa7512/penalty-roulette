# 돌려돌려! 벌칙 룰렛 🎉

모임에서 즐기는 8칸 벌칙 룰렛입니다. HTML, CSS, JavaScript만 사용하며 설치, 회원가입, API 키가 필요 없습니다. 인터넷 연결 없이도 실행됩니다.

## 가장 쉽게 실행하기

1. 이 저장소의 파일을 ZIP으로 내려받고 압축을 풀어주세요.
2. 같은 폴더에 `index.html`, `style.css`, `script.js`가 있는지 확인하세요.
3. `index.html`을 더블 클릭해 Chrome, Edge, Safari 등의 최신 브라우저로 여세요.

오른쪽(스마트폰에서는 아래쪽)의 8개 입력란에서 벌칙을 수정한 뒤 **룰렛 돌리기**를 누르세요. 약 5초 후 화살표가 가리키는 벌칙이 크게 표시됩니다. 회전 중에는 수정과 중복 실행이 잠깐 잠깁니다. 빈 입력란은 `벌칙 1`처럼 표시되고, 각 벌칙은 최대 24자입니다. 모든 칸의 당첨 확률은 1/8입니다.

수정 내용은 브라우저의 로컬 저장소에 자동 저장됩니다. 브라우저 설정이나 파일 실행 방식에 따라 저장이 제한될 수 있으며, 이 경우에도 현재 화면에서 룰렛은 작동합니다. 다른 기기와 동기화되지는 않습니다. **기본값으로** 버튼은 기본 벌칙 8개를 즉시 복원합니다.

## 스마트폰에서 사용하기

화면 너비에 맞춰 자동으로 배치됩니다. 파일을 정적 웹 호스팅(예: GitHub Pages)에 올리면 스마트폰 브라우저에서 편하게 사용할 수 있습니다.

Python이 설치된 컴퓨터에서는 이 폴더의 터미널에서 다음 명령으로 개발 서버를 실행할 수도 있습니다.

```bash
python3 -m http.server 8000 --bind 0.0.0.0
```

컴퓨터에서는 `http://localhost:8000`을 여세요. 같은 Wi-Fi의 스마트폰에서는 `http://컴퓨터의로컬IP:8000`으로 접속합니다. 컴퓨터 방화벽이 연결을 허용해야 합니다. 서버는 `Ctrl+C`로 종료합니다. 이 명령은 개인 컴퓨터에서 사용하는 방법이며 클라우드 환경의 외부 공개 주소를 만들지는 않습니다.

## 파일 구성

- `index.html`: 화면과 입력란, 버튼의 구조
- `style.css`: 화려한 색상, 반응형 배치, 당첨 색종이 효과
- `script.js`: 룰렛 그리기, 무작위 추첨, 회전, 자동 저장

애니메이션 줄이기 설정을 사용하는 기기에서는 회전 시간이 짧아지고 색종이 효과가 생략됩니다. 함께 동의한 가벼운 벌칙으로 즐겨주세요!
